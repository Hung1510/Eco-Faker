# Installation

## As a CLI

```bash
npm install -g eco-faker      # CLI
my-eco-gen --help
```

## As a library

```bash
npm install eco-faker         # as a library
```

## From source

For contributing, running the web playground, or the static browser demo:

```bash
git clone https://github.com/Hung1510/Eco-Faker.git
cd eco-faker && npm install && npm run build
```

See [Run from Source](/getting-started/run-from-source) for the full clone → build → test → generate loop, or [Contributing](/contributing/) if you're planning to make changes.
